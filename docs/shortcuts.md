# Keyboard shortcuts

On macOS, use Cmd where the table says Ctrl/Cmd. On Linux and Windows, use Ctrl.

## Application

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd+K | New quick request |
| Ctrl/Cmd+N | New scenario |
| Ctrl/Cmd+O | Open a `.hurl` file |
| Ctrl/Cmd+Shift+O | Open a workspace |
| Ctrl/Cmd+S | Save the active tab |
| Ctrl/Cmd+Enter | Run the active scenario or quick request |
| Ctrl/Cmd+W | Close the active tab |
| Ctrl/Cmd+B | Show or hide the sidebar |
| Shift+Alt+F | Format the active scenario with `hurlfmt` |
| Enter in the URL bar | Send the quick request |
| Escape | Close a dialog or a menu |

## Text editor and body views

The editor is CodeMirror. The standard key bindings apply.

| Shortcut | Action |
| --- | --- |
| Ctrl/Cmd+F | Search |
| Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z | Undo, redo |
| Tab, Shift+Tab | Indent, outdent |
| Ctrl/Cmd+/ | Toggle a line comment |
