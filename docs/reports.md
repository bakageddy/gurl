# Reports and history

## Report tab

A folder run or a workspace run opens a report tab. The tab shows:

- a header with the number of files, the number of failed files and the total duration,
- a progress bar while the run is in progress,
- a list of files with a status icon and a duration bar,
- the result view of the selected file. See [Running](running.md).

Click a file to select it. Double-click a file to open it in a tab. Click **Cancel** to stop a run that is in
progress.

The result views in a report tab support click-to-assert. gURL opens the scenario and inserts the assert.

## Export

After a run, the report tab offers HURL's own report formats:

- **HURL HTML report**: generates the HTML report and opens it in the browser.
- **Export...**: JUnit XML, TAP, JSON, or HTML. gURL asks for the location.

The reports are generated by HURL from the stored run. Secret values are redacted.

## History

The sidebar has a **History** view. It lists the last 30 runs with their scope, result and time. Click a run to
open its report tab.

gURL keeps the full results of the last 20 runs in memory, including the response bodies. For older runs, the
result view shows the body preview that was stored with the run. The history is cleared when the application
is closed.
